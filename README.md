# CodeAlpha Data Visualization

## 📊 Project Overview

This project was completed as part of the **CodeAlpha Data Visualization Internship Task**.

The objective of this project is to transform raw business data into meaningful visualizations and extract insights that can support data-driven decision-making.

The **Sample Superstore** dataset was analyzed to understand sales performance, profitability, customer segments, regions, products, and sub-categories.

---

## 🎯 Objectives

- Transform raw data into meaningful visual formats.
- Analyze sales and profitability patterns.
- Identify high-performing and low-performing products and categories.
- Compare sales performance across regions and customer segments.
- Create clear and informative visualizations.
- Extract business insights from the visualizations.
- Provide recommendations based on the analysis.

---

## 🗂️ Dataset

**Dataset:** Sample Superstore

The dataset contains transactional information about orders, customers, products, sales, discounts, and profits.

### Dataset Details

- **Records analyzed:** 9,994
- **Columns:** 21
- **Date range:** January 2015 – December 2018

### Important Variables

- Order Date
- Ship Date
- Ship Mode
- Customer Name
- Segment
- Region
- Category
- Sub-Category
- Product Name
- Sales
- Quantity
- Discount
- Profit
